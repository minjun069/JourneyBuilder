## 1. 홈

**화면** 메인 랜딩 / **URL** `/`

화면 구성:

- 상단 NavBar: 좌측 로고 「Journey Builder」, 메뉴 「AI 상담」 「대시보드」 「커뮤니티」, 우측 「로그인 | 회원가입」.
- 히어로: 배지 「재무 건강 진단 서비스」, 제목 「내 재무 상태, 정확하게 파악하세요」, 버튼 「무료로 시작하기」, 체크리스트 4줄.
- 기능 카드 3개: 「재무 대시보드」 「AI 재무 상담」 「커뮤니티」.
- 「시작은 단 3단계」: 01 재무 정보 입력 → 02 AI 재무 분석 → 03 맞춤 전략 확인.
- 하단 CTA 「지금 바로 재무 건강을 점검해 보세요」 와 「무료로 시작하기」.

**클릭·입력**

1. 화면을 아래로 스크롤하며 기능 카드와 3단계를 소개한다.
2. 하단 CTA 의 「무료로 시작하기」 를 누른다.

**기대 결과** 비로그인 상태이므로 `/signup` 으로 이동한다. 로그인 상태라면 `/ai` 로 이동한다.

**시연 멘트** "자산·부채·현금흐름 입력부터 AI 진단, 은퇴 시뮬레이션까지 한 서비스에서 처리합니다."

## 2. 회원가입 · 로그인

### 2-1. 회원가입

**URL** `/signup`

**클릭·입력**

1. 「이름 *」: `시연고객`
2. 「이메일 *」: `demo-live@example.com`
3. 「비밀번호 *」 (8자 이상): `demo-pass-2026!`
4. 「전화번호 (선택)」: `010-1234-5678`
5. 「출생연도 (선택)」: `1990`
6. 「가입하기」 클릭

**기대 결과** 가입 후 자동으로 로그인되고 홈(`/`)으로 이동한다. NavBar 우측이 「로그아웃」 으로 바뀐다.

오류 예시: 이미 가입된 이메일이면 서버 메시지가 폼 아래에 빨간 글씨로 표시된다.

### 2-2. 로그인 (이미 가입된 경우)

**URL** `/login`

1. 「이메일」 과 「비밀번호」 입력
2. 「로그인」 클릭

**기대 결과** 일반 고객은 `/` 로, PB 계정은 `/pb` 로 이동한다. 실패 시 「이메일 또는 비밀번호를 확인해주세요.」 가 표시된다.

## 3. AI 상담

**URL** `/ai` (NavBar 「AI 상담」)

화면은 세 영역으로 나뉜다.

| 영역 | 위치 | 내용 |
|---|---|---|
| 진행 프로세스 | 왼쪽 사이드바 | 24개 단계와 상태 아이콘 (완료 ✓, 현재, 건너뜀, 대기) |
| 채팅 | 가운데 | AI 상담사 「저니」 와의 대화, 입력창 「AI에게 질문해보세요. 예: 은퇴 계획 세워줘」, 「전송」 |
| 데이터 입력 | 오른쪽 패널 | 현재 단계의 입력 폼, 하단 「작성 완료」 |

사이드바 단계 목록:

| 구분 | 단계 |
|---|---|
| 서비스 안내 | 서비스 안내 |
| 고객 정보 수집 | 기본 정보, 경제 관념, 재무 만족도, 재무 정보(금융자산, 연금자산, 부동산자산, 부채, 소득, 지출), 재무목표 |
| 재무 진단 | 재무상태표, 현금흐름표, 가계재무지표, 재무목표, 은퇴 필요자금, 은퇴 준비자금, 은퇴 시뮬레이션, 연금 스케줄, 생애현금흐름 및 생애순자산, 필요저축액 |

AI 처리 중에는 채팅 위에 진행 문구가 순서대로 바뀐다: 「요청을 준비하고 있습니다.」 → 「질문을 분석하고 있습니다.」 → 「필요한 작업을 처리하고 있습니다.」 → 「답변을 최종 확인하고 있습니다.」 등. 처리 중에는 입력과 사이드바가 잠긴다.

### 3-1. 상담 시작

1. 카드 「상담을 어떻게 시작할까요?」 에서 「새 상담 시작」 클릭
2. AI 인사말 「반갑습니다 고객님, 저는 AI 재무상담사 저니 라고 합니다.」 와 소요 시간 안내가 이어진다.
3. 「고객 정보 수집 시작」 클릭

**시연 멘트** "상담은 서버에 세션으로 저장되며 「기존 상담 이어하기」 로 중단한 단계부터 다시 열 수 있습니다."

### 3-2. 개인정보 동의

1. 동의 카드 「개인정보 수집·이용 동의」 의 수집 항목·이용 목적·보유 기간을 보여준다.
2. 「개인정보 수집 및 이용에 동의합니다.」 클릭
3. 「다음 단계로 이동」 클릭 → 「기본 정보」 단계

### 3-3. 기본 정보 — AI 입력 보조와 승인·거절

오른쪽 폼 「기본 정보」: 「나이」, 「직업」, 「기혼 여부」, 「부양가족」, 「소득」(월 세후), 「관심사」, 「니즈」, 투자 성향 태그, 「예상 은퇴 나이」, 「예상 사망 나이」.

1. 채팅에 입력 후 「전송」 (Enter):
   ```text
   월급은 세후 300만 원이고 직업은 직장인으로 정리해 주세요.
   ```
2. AI 가 변경 제안 카드 「아래 변경을 항목별로 확인해주세요.」 를 보낸다. 항목마다 「현재 값」, 「제안 값」, 사유와 「거절」 「승인」 버튼이 있다.
3. 월 소득 항목은 「승인」, 직업 항목은 「거절」 을 눌러 혼합 결정을 보여준다.
4. 승인한 값이 오른쪽 폼에 바로 반영되는 것을 확인한다. 배지가 「승인됨」 / 「거절됨」 으로 바뀐다.
5. 폼의 나머지를 직접 채운다: 나이 `35`, 직업 `직장인`, 기혼 여부 `미혼`, 니즈 `은퇴`, 위험 성향 `균형 추구`, 투자 기간 `장기 지향`, 예상 은퇴 나이 `60`, 예상 사망 나이 `90`.
6. 「작성 완료」 클릭

**기대 결과** 채팅에 「입력하신 정보가 저장되었습니다. 다음 단계로 이동할 준비가 완료되었습니다.」 와 「다음 단계로 이동 →」 버튼이 나온다. 사이드바의 「기본 정보」 에 체크가 표시된다.

**시연 멘트** "AI 는 제안만 하고 저장은 하지 않습니다. 고객이 항목별로 승인한 값만 폼에 들어가고, 「작성 완료」 를 눌러야 DB 에 저장됩니다."

필수값을 비우고 「작성 완료」 를 누르면 「입력 내용을 확인해주세요.」 경고와 항목별 오류(예: 「직업을 선택해주세요.」)가 표시된다.

### 3-4. 경제 관념 — 항목별 대화 수집

1. 「다음 단계로 이동 →」 클릭 → 「경제 관념」 단계
2. AI 가 「경제관념 항목 상담을 시작합니다.」 로 시작해 항목별로 질문한다. 사이드바 「경제 관념」 아래에 6개 항목(가치관, 과거 경험, 현재 상황, 당면 과제, 투자 철학, 미래 목표) 진행 표시가 나온다.
3. 질문에 답한다. 예시:
   ```text
   가족이 돈 걱정 없이 사는 게 가장 중요하다고 생각해요.
   ```
   ```text
   요즘 고민은 은퇴 준비를 시작해야 하는데 매달 얼마를 저축할지 정하지 못한 거예요.
   ```
4. 오른쪽 폼의 해당 칸에 AI 가 정리한 문장이 채워지고 상태가 「대화 중」 → 「정리 완료」 로 바뀐다. 정리된 내용은 직접 수정할 수 있다.
5. 「작성 완료」 클릭 → 「다음 단계로 이동 →」

### 3-5. 재무 만족도

1. 채팅에 표시된 영역 설명(현금흐름 관리, 위험 관리, 투자, 재무관리, 상속)을 보여준다.
2. 5개 항목에 1~5점을 선택한다. 예: `3, 2, 3, 3, 1`.
3. 「작성 완료」 → 「다음 단계로 이동 →」
4. 「재무 정보 안내」 화면에서 「다음 단계로 이동」 클릭

### 3-6. 재무 정보 6단계

각 단계의 오른쪽 폼은 표 형식이며 「+ 행 추가」 로 행을 늘린다. 금액은 원 단위로 입력한다.

| 단계 | 입력 예시 | 비고 |
|---|---|---|
| 금융자산 | 자산 유형 `예금/적금`, 상품명 `급여 통장`, 원금 `5,000,000`, 현재 평가금액 `5,000,000`, 목적 `비상자금` | 빈 폼으로 「작성 완료」 를 누르면 「보유 금융자산 없음」 버튼이 나온다 |
| 연금자산 | 구분 `국민연금`, 평가금액 `12,000,000`, 월 적립액 `300,000`, 개시 연령 `65`, 연금 기간 `종신`, 예상 수령액 `900,000` | |
| 부동산자산 | 구분 `주택/아파트`, 이름 `거주용 아파트`, 평가금액 `450,000,000`, 취득가액 `380,000,000` | |
| 부채 | 구분 `담보대출`, 대출잔액 `200,000,000`, 대출금리 `4.2`, 금리유형 `변동` | |
| 소득 | 구분 `근로소득`, 내용 `급여`, 소득 금액 `3,000,000`, `고정` | |
| 지출 | 항목 `식비/생활비` `1,200,000`, `주거비` `600,000`, `고정` | |

**AI 입력 보조 시연 (금융자산 단계에서 1회)**

1. 행을 하나 입력한 상태에서 채팅에 입력:
   ```text
   급여 통장 잔액을 700만 원으로 고치고, 연금계좌 ETF 1,000만 원을 추가해 주세요.
   ```
2. 수정·추가 제안 카드를 「승인」 → 표에 반영되는 것을 확인한다.

**해당 없음 시연 (한 단계에서 1회)** 폼을 비운 채 「작성 완료」 → 「입력된 내용이 없습니다. 해당 없음으로 진행하시겠습니까?」 → 「해당 없음으로 진행」 → 「해당 내용이 없는 것으로 확인했습니다.」

**질문 시연** 아무 단계에서나 채팅에 입력:

```text
IRP 와 연금저축은 세액공제 한도가 어떻게 달라요?
```

AI 가 승인된 금융 지식 문서(RAG)를 근거로 답한다.

### 3-7. 단계 건너뛰기 경고

1. 현재 단계보다 두 단계 이상 뒤의 사이드바 항목(예: 「재무목표」)을 클릭한다.
2. 모달 「⚠ 미완료 단계 건너뛰기」 가 뜬다. 「… 단계로 이동하면, 아직 처리되지 않은 이전 단계들은 건너뜀으로 표시됩니다.」
3. 「취소」 를 눌러 원래 단계로 돌아온다. (「건너뛰고 이동」 을 누르면 사이 단계가 주황색 건너뜀으로 표시된다.)

### 3-8. 재무목표와 진단 결과

1. 「재무목표」 폼에서 탭 「은퇴 전」 / 「은퇴 후」 를 전환하며 기간별 지출을 입력한다. 예: 은퇴 후 `60~90세 생활비 2,500,000`.
2. 「작성 완료」 클릭

- 사이드바에서 「현금흐름표」 → 「가계재무지표」 → 「은퇴 시뮬레이션」 → 「필요저축액」 순으로 클릭하며 보여준다.
- 채팅에 질문한다:
  ```text
  이 재무상태표에서 가장 먼저 개선할 항목은 뭔가요?
  ```

**시연 멘트** "가계재무지표 7종은 정해진 계산식으로 산출하고, AI 는 계산된 값을 설명만 합니다."

### 7-4. 고객 상세 (`/pb/customers/:id`)

1. 프로필: 이름, 니즈 칩, 나이·직업, 성향 태그, 상태 배지, 「입력 진행률」

5. 「재무 목표」, 「경제 마인드셋」, 「재무 만족도 (1~5점)」, 「상담 세션 이력」 을 스크롤로 보여준다.
