# 금융자산 프로세스 가이드라인
step_id: financial-assets

현재 보유 중인 예·적금, 펀드, 주식, CMA 등 금융자산을 항목별로 입력하는 단계입니다.
각 금융상품의 원금, 현재 평가금액, 월 적립액, 목적을 기록합니다.
여러 상품을 동시에 입력할 수 있으며, 상품마다 하나의 행을 추가합니다.

| 항목명 | field_name | 설명 |
|--------|------------|------|
| 상품명 | name | 금융상품 이름 (은행명 + 상품명) |
| 원금 | principal | 최초 투입한 원금 (원) |
| 현재 평가금액 | value | 현재 시장가 기준 평가금액 (원) |
| 월 적립액 | monthly | 매월 추가 납입하는 금액 (원) |
| 목적 | purpose | 이 자산의 운용 목적 |

---

## name: 상품명
**작성요령**: 금융기관명과 상품명을 함께 입력합니다. 정확한 상품명을 모를 경우 대략적인 명칭도 가능합니다.
**표준값/기준값**: 예: "KB 적금", "신한 CMA", "삼성증권 ETF 계좌", "카카오뱅크 파킹통장"
**제약사항**: 텍스트 자유 입력
**파싱 예시**:
- "국민은행 적금이 하나 있어요" → name: "국민은행 적금"
- "카카오뱅크에 파킹통장 있어요" → name: "카카오뱅크 파킹통장"

---

## principal: 원금
**작성요령**: 해당 금융상품에 최초 또는 누적으로 납입한 원금 총액을 원 단위로 입력합니다. "3천만 원"은 30,000,000 원.
**표준값/기준값**: 한국 가구 평균 금융자산 약 1억 5천만 원 (2024 통계청). 개별 상품 평균 원금 2천만~5천만 원.
**제약사항**: 숫자, 0 이상 (원 단위)
**파싱 예시**:
- "원금은 2천만 원이에요" → principal: 20000000
- "5백만 원 넣었어요" → principal: 5000000
- "3억 투자했어요" → principal: 300000000

---

## value: 현재 평가금액
**작성요령**: 오늘 기준으로 해당 상품을 해지하거나 매도했을 때 받을 수 있는 금액을 원 단위로 입력합니다.
**표준값/기준값**: 적금·예금은 원금+이자, 주식·펀드는 시세 기준. 한국 금융자산 평균 수익률 연 3~4%.
**제약사항**: 숫자, 0 이상 (원 단위)
**파싱 예시**:
- "지금 2,100만 원 정도 돼요" → value: 21000000
- "원금이랑 비슷해요, 한 5천만 원" → value: 50000000

---

## monthly: 월 적립액
**작성요령**: 매월 해당 상품에 추가로 납입하는 금액입니다. 거치식(일시납)이거나 현재 납입 중이 아니면 0으로 입력합니다.
**표준값/기준값**: 한국 가구 평균 월 저축액 약 50만 원. 적금 평균 월 납입액 30만~100만 원.
**제약사항**: 숫자, 0 이상 (원 단위)
**파싱 예시**:
- "매달 30만 원씩 적립해요" → monthly: 300000
- "거치식이라 월 납입은 없어요" → monthly: 0
- "월 50 넣고 있어요" → monthly: 500000

---

## purpose: 목적
**작성요령**: 이 금융자산을 어떤 목적으로 운용하는지 선택합니다.
**표준값/기준값**: 선택지: '자산증식', '목돈마련', '비상자금', '자녀교육', '기타'
**제약사항**: 위 5가지 중 하나 선택
**파싱 예시**:
- "노후 자금 모으려고요" → purpose: "자산증식"
- "집 살 때 쓰려고 모으는 거예요" → purpose: "목돈마련"
- "비상시를 대비한 비상금이에요" → purpose: "비상자금"
- "아이 교육비용으로 쓸 거예요" → purpose: "자녀교육"
