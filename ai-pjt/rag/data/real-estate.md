# 부동산자산 프로세스 가이드라인
step_id: real-estate

현재 보유 중인 부동산 자산(주택, 오피스텔, 상가 등)을 입력하는 단계입니다.
보유 목적(거주용·투자용), 현재 시세, 취득 원가, 임대 수익, 담보대출 현황을 기록합니다.

| 항목명 | field_name | 설명 |
|--------|------------|------|
| 구분 | type | 부동산 유형 |
| 이름 | name | 부동산 명칭 또는 위치 |
| 평가금액 | value | 현재 시세 기준 평가금액 (원) |
| 취득가액 | purchase | 처음 매입한 가격 (원) |
| 취득시기 | date | 매입한 날짜 |
| 월세소득 | monthly | 월 임대 수익 (원, 없으면 0) |
| 임대보증금 | deposit | 임차인으로부터 받은 보증금 (원) |
| 담보대출금 | loan | 해당 부동산 담보로 받은 대출 잔액 (원) |

---

## type: 구분
**작성요령**: 보유 부동산의 유형을 선택합니다.
**표준값/기준값**: 선택지: '주택/아파트', '오피스텔', '빌라', '상가', '기타'. 한국 부동산 자산 중 아파트 비중 65%.
**제약사항**: 위 5가지 중 하나 선택
**파싱 예시**:
- "아파트 한 채 있어요" → type: "주택/아파트"
- "오피스텔 월세 놓고 있어요" → type: "오피스텔"
- "상가를 하나 보유 중이에요" → type: "상가"

---

## name: 이름
**작성요령**: 부동산의 이름(단지명+평형) 또는 위치(동네명)를 입력합니다.
**표준값/기준값**: 예: "강남 래미안 33평형", "수원 영통 오피스텔", "판교 상가 1층"
**제약사항**: 텍스트 자유 입력
**파싱 예시**:
- "분당 정자동 아파트예요" → name: "분당 정자동 아파트"
- "용산구 오피스텔이에요" → name: "용산구 오피스텔"

---

## value: 평가금액
**작성요령**: 현재 시세(공시지가 아닌 실거래가 기준)를 원 단위로 입력합니다.
**표준값/기준값**: 한국 가구 평균 부동산 자산 약 3억 5천만 원 (2024 통계청). 수도권 아파트 평균 시세 약 8억 원.
**제약사항**: 숫자, 0 이상 (원 단위)
**파싱 예시**:
- "지금 시세가 8억 정도 돼요" → value: 800000000
- "3억짜리 빌라예요" → value: 300000000
- "실거래가 기준으로 5억 5천이에요" → value: 550000000

---

## purchase: 취득가액
**작성요령**: 해당 부동산을 처음 구입할 때 지불한 금액입니다.
**표준값/기준값**: 평균 취득 후 자산 상승률 연 3~5% (수도권 기준). 취득가액 대비 현재가 상승이 일반적.
**제약사항**: 숫자, 0 이상 (원 단위)
**파싱 예시**:
- "5억에 샀어요" → purchase: 500000000
- "취득가는 2억 5천이었어요" → purchase: 250000000

---

## monthly: 월세소득
**작성요령**: 해당 부동산에서 발생하는 월 임대료 수입을 원 단위로 입력합니다. 직접 거주 중이거나 전세라면 0.
**표준값/기준값**: 오피스텔 평균 월세 약 80만~120만 원. 상가 평균 월세 약 150만~300만 원.
**제약사항**: 숫자, 0 이상 (원 단위)
**파싱 예시**:
- "월 100만 원씩 받고 있어요" → monthly: 1000000
- "본인이 살고 있어서 월세 없어요" → monthly: 0

---

## deposit: 임대보증금
**작성요령**: 세입자로부터 받은 보증금을 원 단위로 입력합니다. 전세라면 전세금 전액, 반전세라면 보증금 금액.
**표준값/기준값**: 월세 보증금 평균 2천만~5천만 원. 전세 보증금 평균 1억~4억 원 (지역별 상이).
**제약사항**: 숫자, 0 이상 (원 단위)
**파싱 예시**:
- "전세 놨는데 보증금 3억이에요" → deposit: 300000000
- "월세 보증금 2천만 원 받았어요" → deposit: 20000000

---

## loan: 담보대출금
**작성요령**: 해당 부동산을 담보로 받은 대출 현재 잔액을 원 단위로 입력합니다.
**표준값/기준값**: 한국 부동산 담보대출 평균 LTV 약 50%. 평균 담보대출 잔액 약 2억 원.
**제약사항**: 숫자, 0 이상 (원 단위)
**파싱 예시**:
- "주택담보대출 2억 남아있어요" → loan: 200000000
- "대출 없이 샀어요" → loan: 0
- "담보로 5천 빌렸어요" → loan: 50000000
