# 은퇴진단 기본 가정과 경제지표

source_id: retirewise-planning-assumptions-2026
기준일: 2026-09-07
적용 범위: 재무목표, 은퇴자금, 연금일정과 생애 현금흐름 계산의 기본값

## 가정 사용 원칙

- 기본값은 사용자가 값을 입력하지 않았을 때 계산을 가능하게 하는 프로젝트 가정이다.
- 공식 제도값, 외부 통계로 정한 기준값, 프로젝트가 선택한 시나리오를 구분한다.
- 장기수익률과 자산가격 상승률은 예측이나 보장수익률이 아니다.
- 결과에는 실제 사용한 값, 기준일, 출처 또는 `내부 시나리오` 표시를 함께 제공한다.

## 2026년 기본값

| 항목 | 기본값 | 성격과 근거 |
|---|---:|---|
| 장기 소비자물가상승률 | 연 2.0% | 한국은행의 중기 물가안정목표를 장기 기준점으로 사용 |
| 물가 스트레스 시나리오 | 연 3.0% | 공식 전망이 아닌 내부 불리 시나리오 |
| 금융자산 명목수익률 | 연 4.0% | 장기 은퇴계산용 내부 중립 시나리오 |
| 금융자산 상향 시나리오 | 연 5.0% | 목표 달성 보장이 아닌 민감도 비교용 내부 시나리오 |
| 부동산 가치상승률 | 연 2.0% | 지역 예측이 아닌 물가 수준의 내부 장기 시나리오 |
| 근로·사업소득 증가율 | 연 3.0% | 2025년 전체 근로자 명목임금 증가율 3.1%를 단순화한 내부 기준 |
| 임대료 증가율 | 연 2.0% | 지역 예측이 아닌 물가 수준의 내부 장기 시나리오 |
| 임대 공실률 | 5.0% | 공식 평균이 아닌 보수적 내부 차감 시나리오 |
| 은퇴계획 종료연령 | 100세 | 평균수명 예측이 아니라 장수위험을 반영한 보수적 계획 한계 |

## 값 선택 근거와 한계

- 한국은행의 물가안정목표는 소비자물가 상승률 2%다. 실제 연도별 물가는 목표와 다를 수 있으므로 최신 소비자물가와 장기 가정을 구분한다.
- 2025년 전체 근로자 연간 월평균 임금총액 증가율은 3.1%로 공표되었지만 개인의 소득은 고용상태와 경력에 따라 다르다. 3%는 개인 소득을 보장하는 값이 아니다.
- 주택가격은 지역과 유형별 차이가 크므로 한국부동산원 최신 지수는 현황 확인에만 사용하고 2%를 개별 주택 전망으로 표현하지 않는다.
- 금융자산 수익률 4%와 5%, 공실률 5%에는 모두에게 적용되는 공식 표준이 없다. 소규모 서비스의 일관된 계산을 위한 내부값으로만 사용한다.
- 100세는 기대수명이 아니라 계획 종료점이다. 실제 기대여명은 성별과 현재 연령에 따라 달라진다.

## 국민연금 간이 추정에 쓰는 2026년 제도값

| 항목 | 2026년 9월 적용값 | 처리 원칙 |
|---|---:|---|
| A값 | 월 3,193,511원 | 2026년 적용 공식값 |
| 소득대체율 비례상수 | 1.29 | 2026년 공식 급여산식 상수 |
| 보험료율 | 9.5% | 2026년 공식 보험료율. 2033년까지 매년 변경됨 |
| 기준소득월액 하한 | 월 410,000원 | 2026년 7월~2027년 6월 적용 |
| 기준소득월액 상한 | 월 6,590,000원 | 2026년 7월~2027년 6월 적용 |

- 지급개시연령은 단일 65세가 아니라 출생연도별 기준을 적용한다.
- 가입 시작나이, 가입기간, 소득이력에는 통상적으로 안전한 공통 기본값이 없다. 값이 없으면 28세 등 임의 나이를 대입하지 않고 간이 추정의 제한을 알린다.
- 사용자가 국민연금 예상연금액을 입력했거나 공단 조회값을 확인한 경우 그 값을 우선한다.
- 연령만으로 예상연금액을 85%, 90%, 98% 등 일괄 감액하는 보정은 공식 근거가 없으므로 사용하지 않는다.

## 갱신 주기

- 물가목표와 내부 장기 가정은 180일마다 확인한다.
- 국민연금 보험료율과 A값은 매년 1월, 기준소득월액 상·하한은 매년 7월에 확인한다.
- 세법과 연금제도 개정, 계산식 변경 또는 공식 통계 기준개편을 발견하면 주기 전이라도 갱신한다.
- 값을 변경하면 계산 코드, 보고서의 가정 표시, RAG 문서와 검색 평가 질문을 같은 버전으로 변경한다.

- 사용자가 직접 가정을 조정하는 기능이 생기면 기본값과 사용자값의 우선순위, 허용범위와 저장방법을 새 버전으로 정의한다.
