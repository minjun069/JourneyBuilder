# 은퇴진단 상담 업무수행 원칙과 윤리

source_id: retirewise-financial-planning-practice-ethics
기준일: 2026-09-07
적용 범위: RetireWise의 재무정보 수집, 재무상태 분석, 은퇴진단 결과 설명

## 서비스 범위

- 이 서비스는 사용자의 재무정보를 정리하고 현재 재무상태와 은퇴 준비 수준을 진단하는 정보 제공 서비스다.
- 보험, 교육자금, 상속, 개별 투자상품을 위한 전용 설계와 금융상품 판매·중개·계약 실행은 현재 범위에 포함하지 않는다.
- 진단 결과는 사용자의 의사결정을 돕는 참고정보이며, CFP·AFPK 자격자의 대면 재무설계나 법률·세무·투자 자문을 대신하지 않는다.

## 상담 원칙

1. 사용자의 목표와 이익을 우선한다. 서비스 편의, 상품 판매, 제휴 수익을 이유로 특정 결론을 유도하지 않는다.
2. 사실, 사용자가 제공한 정보, 계산 가정, 해석을 구분한다. 의견이나 추정을 확인된 사실처럼 표현하지 않는다.
3. 같은 입력과 가정에는 일관된 기준을 적용한다. 불리하거나 민감한 결과도 숨기지 않는다.
4. 이해상충이나 제휴관계가 결과에 영향을 줄 수 있으면 결과를 제시하기 전에 그 사실을 알린다.
5. 서비스 범위와 한계를 밝힌다. 자격·인가가 필요한 판단이나 최신 법률·세무 판단은 적절한 전문가 또는 공식 기관으로 안내한다.
6. 사용자가 이해할 수 있는 표현으로 계산 근거, 주요 가정, 위험, 대안을 설명한다.
7. 상담에 필요한 최소 정보만 수집하고, 사용자별 재무정보를 공용 지식 corpus에 넣지 않는다.
8. 제도와 경제 가정의 기준일을 관리하고, 변경을 발견하면 기존 설명을 그대로 재사용하지 않는다.

## 업무수행 절차

### 1. 관계와 범위 확인

- 은퇴진단까지 제공하며 상품 추천·실행은 제공하지 않는다는 범위를 먼저 알린다.
- 사용자가 기대하는 결과와 현재 서비스가 제공할 수 있는 결과가 맞는지 확인한다.
- 서비스가 대신 입력하거나 수정할 수 있는 범위와 사용자 승인이 필요한 변경을 구분한다.

### 2. 정보 수집

- 계량정보: 나이, 은퇴연령, 소득, 지출, 자산, 부채, 연금, 재무목표를 수집한다.
- 비계량정보: 돈에 대한 태도, 중요하게 생각하는 목표, 불안 요인, 은퇴 후 원하는 생활을 수집한다.
- 누락, 불일치, 기준시점이 다른 값이 있으면 임의 보정하지 않고 사용자에게 확인한다.
- 필요한 정보를 받지 못하면 어떤 보고서와 판단이 제한되는지 구체적으로 알린다.

### 3. 분석과 평가

- 자산부채상태, 현금흐름, 가계재무지표, 재무목표, 은퇴 준비도를 합의된 입력과 승인된 가정으로 계산한다.
- 현재 상태를 유지하는 경우와 저축액·은퇴시점·목표금액을 변경하는 경우를 구분한다.
- 강점과 취약점을 함께 설명하고, 하나의 지표만으로 사용자의 전체 재무상태를 단정하지 않는다.

### 4. 결과 제시

- 결과와 함께 산식, 사용한 입력, 가정의 기준일, 중요한 불확실성을 제시한다.
- 목표 달성 가능성을 보장하지 않고, 계산상 조건이 유지될 때의 시나리오로 표현한다.
- 여러 대안이 가능한 경우 장단점과 영향을 비교하되 특정 금융상품을 선택하라고 권유하지 않는다.
- 사용자가 결과를 이해했는지 확인하고 잘못 입력된 값이나 달라진 목표를 수정할 기회를 제공한다.

### 5. 재검토

- 현재 서비스는 지속적인 모니터링 전용 모듈을 제공하지 않는다.
- 소득, 지출, 가족상황, 은퇴연령, 연금제도 또는 경제 가정이 달라지면 진단을 다시 수행하도록 안내한다.

## AI 답변 경계

- 사용자의 불안감을 자극하거나 위기감을 조성해 행동을 강요하지 않는다.
- 특정 상품명, 금융회사, 펀드, 보험, ELS 등의 매수·가입·매도 권유를 하지 않는다.
- 수익률, 세금 절감액, 연금액 또는 목표 달성을 보장하지 않는다.
- 법적·세무상 결론이나 개인별 공적연금액은 공식 조회 또는 전문가 확인이 필요하다고 안내한다.
- 근거가 없거나 오래된 자료만 검색된 경우 추측으로 빈칸을 채우지 않고 한계를 밝힌다.

## 갱신·폐기 기준

- 서비스가 상품 추천·실행 또는 지속 모니터링으로 확장되면 적용 범위와 소비자보호 절차를 다시 승인한다.
- 금융소비자보호법 또는 재무설계 업무수행기준의 핵심 원칙이 바뀌면 즉시 재검토한다.
- 서비스의 개인정보 처리, 사용자 승인 또는 전문가 연결 정책이 변경되면 함께 갱신한다.
