# 부채 프로세스 가이드라인
step_id: liabilities

현재 보유 중인 모든 부채(대출, 카드 할부 등)를 입력하는 단계입니다.
부채 규모와 상환 구조를 파악하여 재무 건전성과 월 현금흐름을 정확히 분석합니다.
담보대출, 신용대출, 학자금 대출 등 종류와 관계없이 모두 입력합니다.

| 항목명 | field_name | 설명 |
|--------|------------|------|
| 구분 | type | 대출 유형 |
| 대출 상품명 | name | 금융기관 및 상품명 |
| 대출잔액 | value | 현재 남은 대출 원금 (원) |
| 대출금리 | rate | 연 이자율 (%) |
| 상환방식 | repayment | 원금 상환 방법 |
| 대출일시 | loan | 대출 실행 날짜 |
| 만기일시 | maturity | 최종 상환 예정 날짜 |
| 거치기간 | grace | 원금 상환 없이 이자만 납부하는 기간 (년) |

---

## type: 구분
**작성요령**: 대출의 종류를 선택합니다. 담보 여부와 용도를 기준으로 선택합니다.
**표준값/기준값**: 선택지: '신용대출', '임대보증금', '담보대출', '학자금대출', '기타'. 한국 부채 중 담보대출 비중 약 70%.
**제약사항**: 위 5가지 중 하나 선택
**파싱 예시**:
- "주택담보대출이 있어요" → type: "담보대출"
- "신용대출 받았어요" → type: "신용대출"
- "전세 보증금 받은 게 있어요" → type: "임대보증금"

---

## name: 대출 상품명
**작성요령**: 대출을 받은 금융기관명과 상품명을 입력합니다.
**표준값/기준값**: 예: "국민은행 주택담보대출", "카카오뱅크 비상금대출", "한국장학재단 학자금대출"
**제약사항**: 텍스트 자유 입력
**파싱 예시**:
- "하나은행에서 신용대출 받았어요" → name: "하나은행 신용대출"
- "KB 주담대예요" → name: "KB 주택담보대출"

---

## value: 대출잔액
**작성요령**: 현재 남은 대출 원금을 원 단위로 입력합니다. 이자 포함 총 상환 잔액이 아닌 원금 기준.
**표준값/기준값**: 한국 가구 평균 부채 약 9,200만 원 (2024 통계청). 주담대 평균 잔액 약 2억 원.
**제약사항**: 숫자, 0 이상 (원 단위)
**파싱 예시**:
- "아직 1억 5천이 남아있어요" → value: 150000000
- "3천만 원 남은 거 같아요" → value: 30000000

---

## rate: 대출금리
**작성요령**: 현재 적용되는 연 이자율(%)을 입력합니다. 변동금리라면 현재 적용 금리를 입력합니다.
**표준값/기준값**: 주택담보대출 평균 금리 연 4~5% (2024년 기준). 신용대출 평균 금리 연 6~8%. 학자금 대출 연 1.7%.
**제약사항**: 숫자, 0~30 (%)
**파싱 예시**:
- "금리가 4.5%예요" → rate: 4.5
- "변동금리인데 지금 5.2% 적용돼요" → rate: 5.2
- "저금리 2%짜리에요" → rate: 2.0

---

## repayment: 상환방식
**작성요령**: 대출 원금을 어떻게 갚는지 선택합니다.
**표준값/기준값**: 선택지: '만기일시', '원리금분할상환', '원금분할상환', '기타'. 주담대는 원리금분할상환이 일반적.
- 만기일시: 만기까지 이자만 내고 만기에 원금 일시 상환
- 원리금분할상환: 매월 원금+이자 균등 납부
- 원금분할상환: 원금을 매월 균등 감소, 이자는 잔액 비례
**제약사항**: 위 4가지 중 하나 선택
**파싱 예시**:
- "매달 원금이랑 이자 같이 내요" → repayment: "원리금분할상환"
- "이자만 내다가 만기에 한 번에 갚아요" → repayment: "만기일시"

---

## grace: 거치기간
**작성요령**: 이자만 납부하고 원금 상환이 없는 거치 기간(년)을 입력합니다. 거치기간이 없으면 0.
**표준값/기준값**: 주담대 거치기간 평균 1~3년. 거치기간 없이 바로 상환하는 경우도 많음.
**제약사항**: 숫자, 0~10 (년)
**파싱 예시**:
- "3년 거치 후 상환 중이에요" → grace: 3
- "거치 없이 바로 갚고 있어요" → grace: 0
