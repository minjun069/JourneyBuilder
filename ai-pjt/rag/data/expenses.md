# 지출 프로세스 가이드라인
step_id: expenses

현재 발생 중인 월 지출 항목을 입력하는 단계입니다.
생활비, 보험료, 교육비, 교통비 등 정기 지출과 비정기 지출을 월 단위로 기록합니다.
지출의 고정성 여부도 함께 표시합니다.

| 항목명 | field_name | 설명 |
|--------|------------|------|
| 항목 | name | 지출 항목 이름 |
| 지출 금액 | value | 월 지출 금액 (원) |
| 고정/변동 | fixed | 고정 지출인지 변동 지출인지 구분 |

---

## name: 항목
**작성요령**: 지출 항목 이름을 자유롭게 입력합니다. 상세하게 적을수록 분석에 유리합니다.
**표준값/기준값**: 주요 지출 항목 예시: "생활비(식비)", "주거비(관리비·월세)", "교통비", "보험료", "통신비", "교육비", "의료비", "문화·여가비", "부모님 용돈", "경조사비"
**제약사항**: 텍스트 자유 입력
**파싱 예시**:
- "식비가 제일 많이 나가요" → name: "식비"
- "아이 학원비" → name: "자녀 교육비(학원)"
- "부모님 용돈 드려요" → name: "부모님 용돈"

---

## value: 지출 금액
**작성요령**: 해당 항목의 월 평균 지출 금액을 원 단위로 입력합니다. 비정기 지출은 연 총액을 12로 나눠 월 환산.
**표준값/기준값**:
- 생활비(식비) 평균: 월 40만~60만 원 (1인 가구 30만, 4인 가구 70만)
- 주거비(관리비 등): 월 15만~30만 원
- 교통비: 월 15만~25만 원
- 보험료: 월 20만~50만 원 (가족 단위)
- 통신비: 월 10만~15만 원
- 자녀 교육비(학원): 월 30만~80만 원
- 의료비: 월 5만~20만 원
- 문화·여가비: 월 10만~30만 원
- 부모님 용돈: 월 20만~50만 원
**제약사항**: 숫자, 0 이상 (원 단위)
**파싱 예시**:
- "식비가 월 50만 원 정도 나와요" → value: 500000
- "보험료가 세 가족 합쳐서 35만 원이에요" → value: 350000
- "학원 두 곳에 80만 원 써요" → value: 800000
- "경조사비는 연에 60만 원 정도, 월로 치면 5만 원이에요" → value: 50000

---

## fixed: 고정/변동
**작성요령**: 매월 동일하게 지출되면 '고정', 금액이 달라지면 '변동'을 선택합니다.
**표준값/기준값**: 선택지: '고정', '변동'
- 고정: 보험료, 통신비, 교육비(학원), 대출이자, 구독서비스
- 변동: 식비, 의료비, 문화·여가비, 경조사비
**제약사항**: '고정' 또는 '변동' 중 선택
**파싱 예시**:
- "보험료는 매달 똑같이 나가요" → fixed: "고정"
- "식비는 달마다 달라요" → fixed: "변동"
- "학원비 고정이에요" → fixed: "고정"
