# Presentation 보고서 해석과 연결

source_id: retirewise-presentation-report-interpretation
기준일: 2026-09-17
적용 범위: Chart Agent가 지원하는 Presentation 보고서의 정의, 읽는 순서, 주의사항과 보고서 간 연결

## 공통 해석 원칙

- 숫자, 기간, 계산 결과와 실제 적용 가정은 Backend verified payload만 사용한다.
- 이 문서는 보고서의 의미와 읽는 순서, 주의사항만 제공하며 payload 값을 바꾸거나 새 수치를 제공하지 않는다.
- 변화 원인은 payload의 구조화 사건·구성·변동 근거가 있을 때만 설명한다. 일반적인 가능성을 현재 사용자의 확정 원인처럼 표현하지 않는다.
- 보고서 간 연결은 양쪽이 최신 `ready`이고 입력 snapshot과 계산 정책이 같을 때만 설명한다. 조건이 다르면 이전 보고서로 후퇴하거나 결과를 섞지 않는다.

## 보고서별 정의와 읽는 순서

| 보고서 | 정의와 핵심 지표 | 읽는 순서 | 주의사항과 연결 가능한 보고서 |
|---|---|---|---|
| 자산·부채 현황 | 기준일의 총자산·총부채·순자산과 자산 구성 | 기준일, 총액, 구성, 유동성을 차례로 본다 | 취득가와 현재가를 섞지 않고 현금흐름·은퇴 준비도와 연결한다 |
| 현금흐름 | 같은 기간의 현금유입·현금유출·순현금흐름 | 기간과 월·연 단위, 구성 항목, 순흐름을 본다 | 일회성 항목을 반복 흐름으로 단정하지 않고 가계재무지표·생애 현금흐름과 연결한다 |
| 가계재무지표 | 현금흐름과 자산·부채를 비율 또는 개월 수로 진단한 값 | 지표 정의와 분모, 현재 값, 내부 기준, 입력 누락을 본다 | 규제 지표와 혼동하지 않고 자산·부채 현황·현금흐름과 연결한다 |
| 재무목표 결과 | 목표 시점·필요금액·준비금액·부족액의 결과 | 목표 우선순위, 기간, 적용 가정, 부족액을 본다 | 같은 자산의 중복 배정을 피하고 필요저축액·생애 현금흐름과 연결한다 |
| 은퇴 필요자금 | 은퇴기간 생활비와 연금·준비자산을 반영한 필요금액 | 은퇴기간, 생활비 단계, 연금, 준비자산, 부족액을 본다 | 현재가치와 미래가치를 구분하고 은퇴 준비도·필요저축액과 연결한다 |
| 은퇴 준비도 | 필요자금에 대한 준비자산과 예상 연금재원의 충족 정도 | 필요한 금액, 준비재원, 연금 공백, 유동성을 본다 | 단일 비율만으로 충분 여부를 단정하지 않고 은퇴 필요자금·연금 수령 일정과 연결한다 |
| 은퇴 시뮬레이션 | 동일 조건에서 여러 경로로 계산한 성공확률과 자산 분포 | 입력 snapshot, 정책, 기간, 성공확률, 분포와 고갈사건을 본다 | 보장값으로 해석하지 않고 은퇴 준비도·생애 현금흐름과 연결한다 |
| 연금 수령 일정 | 연금별 개시·종료시점과 수령액의 시간표 | 연금 종류, 개시·종료, 월·연 단위, 중복 여부를 본다 | 세전·세후와 물가연동 여부를 섞지 않고 은퇴 준비도·생애 현금흐름과 연결한다 |
| 생애 현금흐름 | 연령별 유입·유출·순흐름과 자산 변화를 함께 본 장기 보고서 | 기간, 은퇴·연금·생활비 사건, 적자 전환, 유동자산 변화를 본다 | 장기 가정에 민감하며 현금흐름·연금 수령 일정·재무목표 결과와 연결한다 |
| 필요저축액 | 목표 부족액을 기간과 적용수익률에 따라 나눈 정기 저축 요구액 | 부족액, 저축기간, 현재 저축액, 추가 필요액과 가정을 본다 | 수익률을 해결책처럼 제시하지 않고 현금흐름·재무목표 결과·은퇴 필요자금과 연결한다 |

## 은퇴 시뮬레이션 주의사항

- 성공확률, 종료시점 자산의 중앙값과 하위·상위 구간, 자산고갈 여부를 함께 읽고 중앙값 하나만 확정 미래처럼 설명하지 않는다.
- 기준안과 변경안은 같은 입력 snapshot·정책·기간을 사용한 경우에만 비교한다. stale 기준안이나 서로 다른 정책의 결과를 섞지 않는다.
- 확률과 분위수는 미래 수익을 보장하지 않으며 모델 범위 밖의 세금·제도·시장 충격이나 사용자가 입력하지 않은 사건을 원인으로 단정하지 않는다.

## 연결 설명 예시의 경계

- 현재 현금흐름의 적자와 생애 현금흐름의 유동자산 감소는 두 payload에 같은 구성 항목이나 연결 가능한 사건이 있을 때만 함께 설명한다.
- 은퇴 필요자금의 부족액과 필요저축액은 같은 부족액·기간·정책을 공유할 때만 연결한다.
- 연금 개시 전 공백은 은퇴 준비도, 연금 수령 일정, 생애 현금흐름의 호환 payload에 같은 은퇴·연금 사건이 있을 때만 설명한다.

## 갱신·폐기 기준

- Presentation 단계, chart payload schema, 보고서 산식·사건·연결 호환성 정책이 바뀌면 갱신한다.
- 보고서별 전문 승인 문서가 같은 범위를 대체하면 중복 내용을 제거하고 source mapping을 새 문서로 전환한다.
