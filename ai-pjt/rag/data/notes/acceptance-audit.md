# F06-T01·T02 corpus 채택 감사 기록

- 감사일: 2026-09-07
- 대상 branch: `feat/ai-f06-knowledge-rag`
- 상태: 도메인 승인 완료, 운영 인덱싱 전

## 결정

- 서비스 범위는 재무정보 수집, 재무상태·현금흐름 분석, 재무목표와 은퇴진단까지다.
- 분류가 `필수` 또는 `권장`인 금융 지식을 모두 운영 후보 corpus로 채택한다.
- 인터페이스 가이드 10개와 금융 지식 14개만 `catalog.json`의 승인 후보로 관리한다.
- 보험·교육·상속·증여·투자상품 전용 설계, 상품 추천·판매·계약 실행과 지속 모니터링은 제외한다.
- 사용자 제공 PDF는 조사 참고자료이며 파일 원문이나 긴 인용문을 corpus에 넣지 않는다.
- 사용자별 재무정보, 상담 대화와 업로드 문서는 공용 corpus에 넣지 않는다.

## 감사 기준과 결과

| 검사 항목 | 기준 | 결과 |
|---|---|---|
| 식별 | 모든 `id`가 유일해야 한다. | 통과 |
| 경로 | catalog 경로가 허용된 corpus 위치에 존재해야 한다. | 통과 |
| 무결성 | 실제 파일의 SHA-256이 catalog의 `sha256`과 같아야 한다. | 통과 |
| 출처 | 외부 사실은 공식 1차 출처, 내부값은 프로젝트 결정을 식별해야 한다. | 통과 |
| 시점·버전 | 모든 문서에 `as_of_date`와 `version`이 있어야 한다. | 통과 |
| 갱신·폐기 | 문서별 확인 주기 또는 변경 trigger와 폐기 조건이 있어야 한다. | 통과 |
| 라이선스 | 프로젝트가 작성한 요약·사실만 적재하고 외부 원문을 재배포하지 않는다. | 통과 |
| 민감도 | corpus에는 공개 정보와 내부 비민감 정책만 포함하고 개인 재무정보는 없어야 한다. | 통과 |
| 범위 표시 | 내부 기준·시나리오와 법령·공식값이 구분되어야 한다. | 통과 |

검사 시점의 문서 수는 인터페이스 가이드 10개, 금융 지식 14개, 합계 24개다. 실제 운영 적재 시에도 같은 검사를 자동으로 다시 수행해야 하며, 한 항목이라도 실패하면 해당 인덱스 버전을 활성화하지 않는다.

## 품질 기준

- 질문과 직접 관계없는 문서를 근거로 사용하지 않는다.
- 답변에서 외부 사실, 사용자 입력, 계산 가정과 해석을 구분한다.
- 내부 가계재무지표를 국가표준, 법정기준 또는 금융회사 심사기준으로 표현하지 않는다.
- 최신성이 필요한 제도값은 `as_of_date`와 갱신주기를 확인하고 오래된 문서는 단정적 답변에 쓰지 않는다.
- 공식 조회값이 존재하는 국민연금·주택연금·퇴직연금은 사용자 확인값을 간이 추정보다 우선한다.
- 근거가 없거나 상충하면 추측하지 않고 부족한 정보와 공식 확인 경로를 알린다.
- 특정 상품·금융회사·종목을 추천하거나 수익·세금·연금액을 보장하지 않는다.

## 미정 연령구간 보완 결정

원 한국형 가계재무비율 가이드라인이 비워 둔 60~64세와 총부채상환지표 일부 연령대를 2026-09-07 추가 조사로 보완했다.

- 60~64세 가계수지는 95% 이하, 비상예비금은 6배 이상, 총저축성향은 5% 이상으로 정한다.
- 총부채상환은 20~49세 25% 미만, 50~59세 20% 미만, 60~64세 10% 미만, 65세 이상 0%로 정한다.
- 법정 정년 60세와 1969년생 이후 국민연금 정상 개시 65세 사이를 `은퇴전환기`로 정의한다. 이 구간의 소득 중단 위험에는 6개월 유동성을 적용하고, 부채상환 부담은 65세의 0% 목표를 향해 낮춘다.
- 원 연구가 제시하지 않은 20%, 10%는 법령·국가표준·대출심사 기준이 아니라 RetireWise 내부 감축 경로다.
- 이 결정으로 연령 기준 공백은 없어진다. 연령 또는 산식의 필수 분모가 없을 때만 `판정 불가`를 반환한다.

결정 근거는 한국FP협회의 재무비율 가이드, KCI에 등재된 원 연구 서지, 60세 이상 정년 제도, 국민연금 출생연도별 지급개시연령과 일반적인 3~6개월 비상자금 범위다. 상세 URL과 기준 성격은 `household-financial-indicators.md`에 유지한다.

## 승인하되 구현 전에 해소할 차이

지식 문서의 채택과 현재 계산 결과의 승인은 다르다. 현재 계산 코드에는 물가 스트레스 2.6%, 부동산 상향 3%, 국민연금 기준소득월액 39만~617만 원, 일괄 개시연령 65세와 가입 시작 28세 가정이 남아 있다. 총저축성향, 비상예비금, 노후대비저축의 분모도 승인된 내부 지표와 다르다.

이 corpus는 F06-T04 승인 인덱싱과 F06-T05 검색 평가를 통과했다. 계산 코드 차이는 F09-T07 별도 작업으로 이관했으며, 그 정합화와 실제 Gemini 평가가 끝나기 전에는 `financial-knowledge` 활성 인덱스를 운영 승격하지 않는다.
