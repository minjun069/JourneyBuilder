Agent 별 구현 로직


-(AI) agent 로직 구현 input_assist

-입력 정보 파악 (사용자 요구사항 특정 = classify intent)

--사용자 요구사항 = 1. 특정 항목(들)에 적당한 값(평균 등)으로 채워달라
--사용자 요구사항 = 2. 특정 내용(값)을 입력하고 싶은데 어느 항목(들)에 어떻게 입력할지 모르겠다
--사용자 요구사항 = 3. 특정 항목(들)에 정리되지 않은 내용을 정리해서 입력해달라
--사용자 요구사항 = 4. 기타

-항목 특정 
[전체 항목 내용 명세서]
[사용자 입력]
-> list (항목1-사용자 입력 중 해당 내용 발췌, 항목2-사용자 입력 중 해당 내용 발췌, ...)


각 [항목-발췌내용]에 대해

-오류 검토 1
[전체 항목 내용 명세서]
->사용자 요구사항과 다른 항목으로 배정된 오류에 대해 오류 내용
->항목 특정
(재시도 x, 생성된 오류 내용 사용하지 않음 ai 논리성을 위해 생성하도록 함)

-값 확정
[항목 별 명세서 - 작성요령, 표준값, 사용자 입력으로부터 작성 예시, 제약사항] + (재시도 시) [오류 이유]
--사용자 요구사항 1. 값 검색 
--사용자 요구사항 2. 값 파싱
--사용자 요구사항 3. 값 정제
-> 확정된 값

-오류 검토 2
[해당 항목 별 명세서]
--오류 1. 사용자 요구사항에 명세되지 않은 값 (할루시네이션) 
--오류 2. 값이 정리되지 않음
--오류 3. 자료형 또는 단위 등 이상
--오류 4. 값의 합리성 여부 (검색 실패 또는 검색 내용 반영 실패)
-> 오류 발생 시 값 [오류 이유] 반환 및 확정 재시도

(오류가 없을 경우 또는 최대 재생성 횟수 초과 시)
-사용자 안내 멘트 작성
-> 이러한 이유로 이 항목에 이 값을 입력했음....

(남은 항목이 있을 경우)
-다음 항목에 대해 오류 검토 1 수행

(남은 항목이 없을 경우)
-사용자 안내멘트 합치기

-프로세스 항목 별 가이드라인 호출 및 검토, 오류 탐지 시 이유 작성
-정답 값 추정 및 이유 작성
(다음 순서대로 검토 중 값이 특정될 경우 멈춤)
--프로세스 가이드라인 검토
--고객 정보 검토
--채팅 내역 검토

(모든 항목 오류 없을 시)
전체 항목 한번에 검토
-프로세스 가이드라인 호출 및 전체 데이터 한번에 검토, 오류 탐지 시 해당 항목과 이유 작성
(오류가 탐지된 항목들 별)
-정답 값 추정 및 이유 작성
(다음 순서대로 검토 중 값이 특정될 경우 멈춤)
--프로세스 가이드라인 검토
--고객 정보 검토
--채팅 내역 검토

-(AI) agent 로직 구현 elicit

한 번에 이루어지지 않고, 사용자와 멀티 턴에 걸쳐 대화하며 값을 완성해 나가야 함

한 항목에 대해 몇번째 턴인지 기록해야 하고,
턴 횟수 및 값 완성도에 따라서 질문이나 유도문을 다르게 작성하도록 함

가이드라인이 철저하게 작성되어야 가능한 부분
